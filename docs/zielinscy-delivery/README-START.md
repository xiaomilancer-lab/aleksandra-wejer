# Pakiet rezerwacji online - Centrum Medyczno-Estetyczne Zielińscy Premium

Pakiet zawiera gotowy kafelek na stronę internetową, materiały Facebook i Instagram, relację Stories, statyczny kod QR oraz proste instrukcje użycia.

## Od czego zacząć

1. Instrukcja dla właścicielki Centrum: `06-Instrukcja/CO-DOSTALAM.md`
2. Instrukcja dla administratora strony: `01-WWW/INSTRUKCJA-WDROZENIA.md`
3. Gotowe teksty do publikacji: `06-Instrukcja/GOTOWE-TEKSTY-COPY-PASTE.md`
4. Wszystkie linki partnerskie: `06-Instrukcja/LINKI-PARTNERSKIE.md`

Centrum nie instaluje systemu rezerwacyjnego i nie kopiuje kalendarza na swój serwer. Widget, posty i QR kierują do dedykowanej strony Aleksandry. Aktualne terminy pozostają obsługiwane w systemie na `aleksandrawejer.pl`.
